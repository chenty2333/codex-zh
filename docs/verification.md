# 验证记录

本次验证：2026-09-10，Linux，Node.js 24.15.0，Codex CLI 0.154.0。

33 项自动化测试、语法检查、真实 app-server 重启恢复、真实 TUI 与 20,000 回合内存测试均通过。两条真实 DeepSeek 整文请求正常完成，返回正文未做内容或格式判定。

## 自动化测试

`npm test` 的 33 项测试覆盖：

- 完整原文一次发送，包括多段文字、代码、产品型号、数字和引号内容；返回正文直接使用。
- 双向翻译通过普通文字请求和返回值衔接，不要求 JSON 译文封装。
- 限定输入/输出字段变换；附件、模型配置、工具、审批和未知消息透传。
- 提交译文时清空原文位置注解，当前输入回显仍恢复原始文字与注解。
- 输入请求失败不提交；原生补齐默认字段后仍能匹配中文输入回显。
- 原生完成条目提供完整原文，当前显示、完成条目和回合快照使用同一份返回文字。
- 历史读取和恢复保持原生文字，不再次调用翻译。
- 连续 1,000 轮后临时记录与队列清空；长回合的接纳容量与资源释放。
- 大译文直接显示，按实际字符数记账，回合完成后释放。
- 慢请求与中断，以及 HTTP、超时、网络等请求失败的原文回退。
- UTF-8 拆包、CRLF SSE、接口失败事件和连接提前结束。
- 真实本地 WebSocket → 子进程 stdio 的往返，以及未鉴权连接的拒绝。
- 慢翻译期间额外回复的背压及后续完整转发。
- 退出提示跟随成功的会话选择，忽略普通读取和后台会话；处理归档、删除与临时会话。
- 恢复命令无需目录参数，正确引用带空格、引号和 shell 特殊字符的配置名称。
- 主连接和历史选择器同时连接、请求 ID 重复、选择器关闭后主连接继续可用。

原有占位符、字面量保护、译文内容与格式校验测试已删除。测试中的固定返回值用于验证程序转发行为，不评判真实模型的翻译质量。

`npm run check` 进行 JavaScript 语法检查和源码凭据模式扫描。

## 原生程序验证

`npm run test:native` 启动真实 `codex app-server --stdio`，使用本地确定性 Responses 模型端点，验证中文输入被转换成英文进入模型、原生 v2 消息返回中文，以及显示与最终回复一致。随后关闭代理和后台，启动全新后台并 `thread/resume`：旧消息保持原生英文且不触发翻译，新消息继续双向翻译。还检查原生 rollout 未保存测试中文输入和中文译文，回合完成后临时字符数归零。测试后归档此次创建的合成会话。

`npm run test:tui` 通过 Python PTY 启动真实 Codex TUI 和 app-server。输入“请测试翻译桥接。”，本地模型收到英文，TUI 显示“桥接已就绪。”，正常 `/quit` 返回状态 0。前后比较原生输入历史中的测试 prompt 数量，确认不会额外保存中文输入。随后在不同目录使用退出提示中的短命令重启恢复同一会话，确认沿用原工作目录，再验证 `resume --last`。

另外用原生 `codex` 创建并命名合成会话，在 `codex-zh` 内通过 `/resume` 搜索、选中该会话并继续中文对话；再用原生 `codex` 恢复代理创建的会话，验证双向共享历史。测试后归档此次创建的合成会话。各阶段记录在 `.test-state/tui/` 下的 `start/`、`resume-id/`、`resume-last/`、`native-start/`、`slash-resume/`、`native-resume-bridge/`。Codex 模型和 DeepSeek 端点都是本地模拟，不调用真实模型。

## 长对话内存检查

`npm run test:memory` 使用真实代理和本地确定性翻译器，连续处理 20,000 个不同的输入/回复回合。每轮检查临时字符数、条目数、输入映射、待处理请求、控制器与队列均清零。每 4,000 轮强制 GC 并记录 heapUsed/RSS；预热后的堆增长须小于 8 MiB。具体样本写入 `.test-state/memory/report.json`，不测量原生 TUI 的历史内存。

## 真实 DeepSeek 示例

`npm run test:live` 将两条完整合成原文发送给真实 `/responses` 与 `deepseek-flash`，分别请求英文和中文翻译。仅记录接口返回结果，不检查字面量、换行、措辞、语义或格式。原文与返回结果写入被 Git 忽略的 `.test-state/live/report.json`，供人工查看；普通运行不会记录用户对话译文。

## 未覆盖的兼容性

没有穷举全部原生工具、插件、操作系统或未来 Codex 版本。原生 TUI 的菜单、推理摘要和工具日志仍可包含英文。退出即停止本地后台；本版不支持断开后继续执行。
